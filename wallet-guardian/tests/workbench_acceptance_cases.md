# 錢包瀏覽器任務工作台驗收案例（31）

接在 v2 後面，不取代監控與唯讀邊界。這些是離線政策案例，不是上線證明，也不是主網資產交易授權。

手機錢包內建瀏覽器：未測。模式 A 真錢包：未測。模式 B 真錢包：未測。模式 C：不支援（沒有已驗證的鏈上強制機制）。

| ID | 說明 |
|---|---|
| W01 | 任務連結不是執行授權 |
| W02 | 連結不帶地址或金額等私人狀態 |
| W03 | 其他租戶不能用同一參考碼打開任務 |
| W04 | 代理輸出必須是固定任務版本 |
| W05 | 拒絕運行時簽名腳本 |
| W06 | 工作區不接受 session 秘密或 WalletConnect URI |
| W07 | Lista 單步領取不要求 EIP-7702 |
| W08 | Lista 單步領取不要求無限授權 |
| W09 | 單步領取不新增管理員、不遷移資產、不升級帳戶 |
| W10 | 連接、登入、授權、批次、執行權限、升級與確認分開，只有確認是必要步驟 |
| W11 | 不支援批次時退回模式 A |
| W12 | 已查到同鏈批次能力可選模式 B，但不送出，真錢包未測 |
| W13 | 跨鏈或未知能力不進入批次 |
| W14 | 模式 C 只有鏈上強制機制驗證通過才啟用 |
| W15 | 限制欄位不全不能啟用模式 C |
| W16 | 新智慧帳戶不能操作原地址既有部位 |
| W17 | 單步 Lista 即使錢包支援批次仍留在模式 A |
| W18 | idx 或實作變更時停止並要求重新確認 |
| W19 | 金額、接收人、到期、暫停或不可領取都要重新確認 |
| W20 | 等待期可追蹤但不能跳過 |
| W21 | 使用者拒簽不自動重試 |
| W22 | 部分成功維持部分成功 |
| W23 | 送出不明不另開一筆交易 |
| W24 | 交易替代的舊雜湊與新雜湊都不是完成 |
| W25 | 重複請求不再送出 |
| W26 | 撤銷不追回已轉出資產；權限到期退回模式 A |
| W27 | 交易雜湊本身不是完成，必須核對鏈上結果 |
| W28 | 手機內建瀏覽器與模式 A／B／C 的證據分開標示；手機與 A／B 未測，C 不支援 |
| W29 | 建置工作台不是主網執行授權 |
| W30 | 沒有固定 HTTPS 網域就不發行公開任務連結 |
| W31 | ready 能力不自動升級帳戶 |
